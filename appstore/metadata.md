# 심해 다이버 — 앱스토어 메타데이터 초안 (한국어)

> ASO 원칙(퐁퐁 때 확립): 브랜드명 + 검색어 뭉치. 이름 30자 / 부제 30자 / 숨은 키워드 100자.
> 실제 제출 전 사용자 확인 필수 — 이 문서는 초안.

## 이름 (30자 이내) — 후보 3안

1. **심해 다이버 : 바다 탐험 힐링 게임** (18자) ← 추천. 힐링+탐험 검색 뭉치
2. 심해 다이버 - 물고기 도감 바다 잠수 (19자) — 도감/물고기 검색 강화
3. 심해 다이버 : 심해 생물 탐험 다이빙 (19자)

## 부제 (30자 이내) — 후보 3안

1. **실존 심해 생물 28종을 관찰하는 잠수 탐험** (22자) ← 추천
2. 세계 8대 해구를 내려가는 힐링 다이빙 (19자)
3. 바다 도감을 채우는 심해 탐험 게임 (17자)

## 프로모션 텍스트 (170자 이내)

> 수면에서 마리아나 해구까지. 내려가는 건 반, 살아 돌아와야 진짜 클리어!
> 초롱아귀의 미끼 불빛, 철 갑옷 고둥, 유령문어… 실존 심해 생물 28종이 기다립니다.

## 카테고리

- **기본**: 게임 > 캐주얼
- **보조**: 게임 > 어드벤처 (또는 앱 보조 카테고리로 "교육" — 도감 콘텐츠 근거.
  단, 교육 카테고리는 심사에서 교육성 근거를 볼 수 있으니 1차 제출은
  캐주얼+어드벤처가 안전, 도감 콘텐츠가 쌓이면 교육 전환 검토)
